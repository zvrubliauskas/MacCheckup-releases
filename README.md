# Mac Checkup — downloads

Mac Checkup diagnoses network, Wi-Fi, speed, performance, battery, backup and security problems on a Mac, and explains what it finds in plain English.

- **Download:** the latest `.dmg` is under [Releases](../../releases/latest). Open it and drag **Mac Checkup** onto **Applications**.
- **Requires:** macOS 14 or later (Apple silicon or Intel) and a **license key**, which you get from the developer.
- **Updates:** installed copies check for updates daily and install them with one click.

Every build is signed with a Developer ID, notarized by Apple, and every update is additionally verified with the developer's signing key.

This repository contains only release downloads and the update feed (`appcast.xml`). The source code is not published.
